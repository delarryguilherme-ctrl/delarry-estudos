# Delarry Estudos

Caderno de estudos no navegador: cada caderno é um texto contínuo, que pode ser montado como um livro de papel (pauta, luz de abajur e tinta renderizadas em WebGL).

- Pastas e cadernos na biblioteca, com busca, reordenação e importação de pastas e arquivos `.md`
- Editor com títulos, listas, checklists, tabelas, fotos, vídeos e exemplos interativos
- "Montar livro": paginação automática em folhas de caderno, só leitura
- Tudo fica salvo no próprio navegador (IndexedDB); use **Importar → Fazer backup** para guardar uma cópia

Abra `index.html` no navegador ou acesse a versão publicada no GitHub Pages.
