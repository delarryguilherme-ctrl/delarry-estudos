# Direção visual

---

Direção visual é o conjunto de decisões que define como um produto deve parecer e soar: paleta, tipografia, imagens, formas, tom. Para quem desenha interfaces, ela vem antes dos componentes e das telas. Sem uma direção combinada, cada tela vira uma escolha isolada e o produto perde coerência. Com ela, o time tem um critério para dizer "isto combina" ou "isto não combina" sem depender só de gosto pessoal.

O módulo segue o caminho que um projeto costuma fazer na prática. Primeiro, você junta referências e as organiza num moodboard, para descobrir o que o projeto quer transmitir. Depois, transforma essas referências em propostas concretas, com o conceito visual e os style tiles, que permitem conversar com o cliente antes de desenhar telas completas. Por fim, o terceiro caderno amarra a direção ao que veio da pesquisa com usuários, para que ela não seja apenas estética, e sim uma resposta ao público e ao problema.

## Leituras

- Samantha Warren — [Style Tiles](https://styletil.es/) (o site da criadora do método, com explicação, exemplos e modelos).
- Samantha Warren — [Style Tiles and How They Work](https://alistapart.com/article/style-tiles-and-how-they-work/) (artigo na A List Apart que explica o processo e a diferença para um layout completo).
- Brad Frost — [Atomic Design](https://atomicdesign.bradfrost.com/) (livro gratuito online; mostra como uma direção visual vira um sistema de componentes).
- Adam Wathan e Steve Schoger — [Refactoring UI](https://www.refactoringui.com/) (dicas práticas de hierarquia, cor e espaçamento para quem desenha interfaces).
- Apple — [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) (referência oficial para ver como uma plataforma define cor, tipografia e imagens).
- Google — [Material Design 3](https://m3.material.io/) (outro exemplo de sistema visual documentado, útil para comparar com a HIG).
